# Project Instructions

## Code Modification Policy

- Treat all requests as read-only by default.
- Do not modify, create, delete, rename, format, or refactor code unless the user explicitly requests a code change.
- This includes source files, headers, CMake files, linker scripts, and CubeMX-generated project configuration.
- Analyze, inspect, explain, and provide suggestions only.
- If a code change appears necessary, ask for explicit permission before applying it.
- Requests such as "check", "look at", "analyze", or "why" mean read-only inspection, not code modification.
